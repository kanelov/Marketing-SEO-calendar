# Marketing SEO Calendar

Самостоятелно интерактивно приложение за маркетинг календар, SEO категории, email HTML, блог постове, рекламни текстове и топ продукти за няколко сайта/профила.

## Стартиране

Отвори `index.html` директно в браузър. Данните се пазят локално чрез `localStorage`, а при попълнени Supabase настройки се синхронизират автоматично.

## Supabase

1. Създай Supabase проект.
2. Изпълни SQL файла `supabase/schema.sql` в SQL Editor.
3. Отвори приложението и избери `Supabase настройки`.
4. Въведи Project URL и public anon key.
5. След това приложението автоматично зарежда и записва профили и карти.

Важно: текущата примерна политика позволява публично четене и запис, за да може приложението да работи без login. За продукционна употреба е по-добре да се добави автентикация и по-строги RLS политики.
